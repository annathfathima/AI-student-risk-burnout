# AI Student Risk Burnout Prediction using Deep Learning

## Project Overview
This project predicts student burnout risk using a Deep Learning model built with TensorFlow and Keras. The model analyzes academic, personal, and lifestyle factors to classify students based on their burnout risk.

## Features
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Deep Learning Model Training
- Model Evaluation
- Burnout Risk Prediction

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- TensorFlow
- Keras

## Deep Learning Model
- Model: Sequential Neural Network
- Optimizer: Adam
- Loss Function: Categorical Crossentropy
- Framework: TensorFlow/Keras

## Workflow
1. Load the dataset
2. Preprocess the data
3. Perform Exploratory Data Analysis (EDA)
4. Build the Sequential Deep Learning model
5. Train the model using the Adam optimizer
6. Evaluate model performance
7. Predict student burnout risk

- Improve model accuracy
